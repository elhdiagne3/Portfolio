Résumé technique

Data Scientist orienté production, spécialisé en machine learning supervisé, traitement du langage (NLP) et déploiement de modèles en production. Expérience end-to-end : exploration de données volumineuses, feature engineering, entraînement et évaluation de modèles, monitoring post-déploiement.

Maîtrise de Python (Pandas, NumPy, scikit-learn, PyTorch) et SQL (PostgreSQL, BigQuery). Pratique quotidienne de Docker, MLflow, FastAPI et Git pour industrialiser les pipelines. Sensibilité aux contraintes métier : coût d'erreur, latence, interprétabilité.

Intérêt marqué pour les modèles parcimonieux, les architectures reproductibles et les workflows MLOps (CI/CD, versionnement de données, tests de modèles).
