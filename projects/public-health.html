Application Data · Santé publique

Public Health Dashboard

Python · Streamlit · Pandas · Plotly

Contexte

Application interactive de suivi d'indicateurs de santé publique : exploration des tendances épidémiologiques, comparaison régionale, filtres dynamiques et visualisations temps réel. Objectif : fournir un outil de pilotage simple pour des décideurs non techniques.

Fonctionnalités clés

  • Tableau de bord filtrable (région, période, pathologie)
  • Séries temporelles interactives (Plotly)
  • Cartes choroplèthes de prévalence
  • Export CSV des sous-ensembles filtrés
  • Cache et pré-agrégation pour répondre en moins de 200 ms

Stack & architecture

Pipeline ETL en Python (Pandas) → stockage Parquet → application Streamlit containerisée via Docker, déployée sur Streamlit Community Cloud. Tests unitaires sur les transformations métier critiques.
