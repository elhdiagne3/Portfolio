Prédiction du churn client

Python · scikit-learn · XGBoost · MLflow

Contexte

Un opérateur télécom perd ~25 % de ses clients par an. Objectif : identifier les clients à risque pour cibler les campagnes de rétention.

Données

Dataset public Kaggle : 7 043 clients, 21 variables. Déséquilibre 73/27 en faveur des non-churners.

Méthodologie

  • Nettoyage et feature engineering (ancienneté, ratio charges/services).
  • Encodage one-hot, scaling sur variables numériques.
  • Comparaison LogReg / RandomForest / XGBoost avec validation croisée 5-fold stratifiée.
  • Optimisation bayésienne (Optuna) + seuil calibré sur coût métier.
  • Suivi des expériences avec MLflow.

Résultats

  • ROC-AUC : 0,86 (XGBoost)
  • Recall (classe churn) : 0,79
  • Gain estimé : 12 % de churn évité sur échantillon test

Limites & pistes

Dataset statique, pas de données temporelles. Pistes : features comportementales, modèle de survie, déploiement API avec monitoring.
