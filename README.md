## Personnalisation

1. Remplacez `[Prénom Nom]`, `vous@example.com`, `votre-user`.
2. Ajoutez `images/profile.jpg`, `cv.pdf`.
3. Remplacez le contenu des études de cas.

## Déploiement

    git remote add origin https://github.com/VOTRE-USER/VOTRE-USER.github.io.git
    git push -u origin main

Settings → Pages → Deploy from a branch → main / root.
